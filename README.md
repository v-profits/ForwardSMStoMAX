# update_final7 — устранён повтор сообщения (гонка пакета и фоновой очереди)

## Что было
14.11 в 08:19:08 сообщение «Котельная Офис» ушло в MAX дважды: сразу две отправки
(idMessage …989 и …996) из одной записи очереди №20. Закрытие окна пакета и фоновая
очередь (проверка раз в 10 мин и через минуту после пакета) одновременно прочитали
одну и ту же запись из БД и обе её отправили. Из-за медленного ответа GREEN-API
(отправка идёт десятки секунд) окна пересеклись.

## Что сделано
1. Общий набор «записи в отправке»: запись, которую взял пакет или фоновая очередь,
   второй поток пропускает. После отправки (или неудачи) запись освобождается.
2. Пометка `[из очереди]` в журнале — только у сообщений с 🔄 (раньше стояла у всех).
3. Запись «Отправка запущена будильником» больше не пишется, если отправлять нечего
   (раньше она появлялась после обычных SMS без фильтра, например от МТС).
